📊 Distributional fidelity — Kolmogorov–Smirnov by release

Lower KS = synthetic marginals closer to source. The horizontal line at 0.05 is the conventional "indistinguishable from same distribution" threshold; below that a two-sample test fails to reject the null at α=0.05.

🧮 Correlation magnitude recovery — by pair type

Ratio of synthetic-vs-source Spearman correlation magnitude, averaged across all pairs of the indicated type. v0.5 polyserial+tetrachoric fix lifts mixed-type pairs from ~50–65% to ~90%+ of source.

🎯 Downstream utility — TSTR (train on synthetic, test on real)

Risk-model ROC-AUC when trained on syntha-generated data vs trained on the source data. Closer the two columns, the better synthetic transfers to real-data tasks. Populated by benchmarks/synthehrella_run.py on each release once v0.5.6 lands.

🔐 Privacy — membership inference + attribute inference

ROC-AUC of an attacker trying to determine whether a real source row was in the training set (membership inference) or guess held-out attributes (attribute inference). 0.50 = chance, 1.00 = perfect attack. DP-SGD variants of syntha (v0.5.3) push both toward 0.50. Placeholder until v0.5 G2 lands.
